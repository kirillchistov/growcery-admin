Growcery Admin

Административная панель для eGrocery

О проекте

Next.js 15 приложение с аутентификацией, PostgreSQL и Drizzle ORM. GitHub Pages показывает эту статическую страницу; полная интерактивная версия требует серверного окружения (Vercel или self-hosted).

  • Дашборд с аналитикой и графиком выручки
  • Управление клиентами, проектами и счетами
  • NextAuth + PostgreSQL + Drizzle ORM
Исходный код Инструкция по установке

Локальный запуск

git clone https://github.com/kirillchistov/growcery-admin.git
cd growcery-admin
pnpm install
cp .env.example .env.local
pnpm db:push && pnpm db:seed
pnpm dev
